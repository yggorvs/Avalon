Tenha instalado o Python 3.11 para executar

Crie o ambiente virtual venv com o comando bash "python -m venv venv"

Ative o ambiente no terminal ".\venv\Scripts\activate"

Use o comando bash para instalar as dependências "pip install -r requirements.txt"

Execute o arquivo python "main_gui.py"

Clique em INICIAR ESCUTA para ativar o microfone.

O núcleo passará do modo Dourado (Standby) para o Verde (Captura/Processamento).

Diga "Avalon" para o sistema entrar no modo de escuta

Fale seu comando e aguarde a resposta do AVALON.
